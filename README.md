# 📊 Sales Analysis: Анализ данных о продажах с визуализацией  

Проект демонстрирует анализ реальных (или синтетических) данных о продажах с использованием Python, pandas и библиотек визуализации.  

**🔹 Для кого это полезно:**  
- Начинающим Data Analyst / Data Scientist  
- Продакт-менеджерам  
- Маркетологам  

---

## 🛠️ Технологии  
- **Python 3.10+**  
- **Pandas** — обработка и анализ данных  
- **Matplotlib + Seaborn** — визsales_analysis/  
- **Jupyter Notebook** (опционально)  

---

## 📁 Структура проекта  
sales_analysis/  
├── data/  
│   └── sales_data.csv            # Исходные данные  
├── sales_analysis.py             # Основной скрипт анализа  
├── sales_analysis.ipynb          # Jupyter Notebook (альтернатива)  
├── outputs/  
│   ├── sales_by_product.png      # График продаж по продуктам  
│   └── monthly_sales_trend.png   # Тренд по месяцам
